> 文档版本：v1.0
> 创建日期：2026-07-11

## 一、阶段 0：开局前准备（30 分钟，必须先做）

**这一步在主窗口执行**，完成后两个开发窗口才能开。

### 步骤 0.1：路由补齐（5 分钟）

**文件**：`src/router/index.js`

**改动**：在 `/biz` 父路由下追加 `contract` 和 `customer` 子路由（**这两个之前已经写好代码但没注册到路由**）。

找到这段代码：
```javascript

  permissions: ['biz:view'],
  children: [
    {
      path: 'approval',

      name: 'BizApproval',
      meta: { title: '审批中心', icon: 'check', noCache: false }

}
```

改为：
```javascript
{
```

### 步骤 0.4：controller 自动注册（5 分钟）

## 三、阶段 2：合并 + 端到端验收

### 步骤 3.1：拉取最新代码

```bash
# 窗口 B 先提交
cd <workspace>
git add .
git commit -m "v3.0-路线B: 战略驾驶舱 + dashboard + profile + system"
git push origin feature/route-b

# 窗口 A 提交
cd <workspace>
git add .
git commit -m "v3.0-路线A: 业务闭环 4 模块（channel/invoice/finance/operation）"
git push origin feature/route-a

# 主窗口合并
cd <workspace>
git checkout main
git merge feature/route-a
git merge feature/route-b
```

## 四、冲突预警与处理

| 冲突场景 | 处理方式 |
|---------|---------|
| 窗口 A 和 B 同时改 `src/router/index.js` | 各自只追加自己的行，不调整顺序 |
| 窗口 A 和 B 同时改 `module_biz/__init__.py` | 阶段 0 已一次性注册好，后续不动 |
| 窗口 A 改了 `module_biz/enums.py`，窗口 B 没动 | merge 自动合并（路线 B 不动 enum） |
| 窗口 B 改了 `src/router/index.js`，窗口 A 也改了 | 手动合并两边的 children |
| 路线 B 的 cockpit 找不到路线 A 的表 | 阶段 0 已确保表结构稳定，B 用 try/except 兜底 |
