## 一、设计原则

### 1.1 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| **数据库** | 小写下划线 | `sd_publish_scm` |
| **表名** | 小写下划线，前缀区分类型 | `biz_contract`, `sys_user` |
| **列名** | 小写下划线 | `user_name`, `created_at` |
| **主键** | `id` | 统一使用 `id` |
| **外键** | `{表名}_id` | `user_id`, `contract_id` |
| **时间戳** | `{action}_at` | `created_at`, `updated_at` |
| **布尔值** | `is_{描述}` | `is_deleted`, `is_active` |

### 1.2 表前缀说明

| 前缀 | 含义 | 示例 |
|------|------|------|
| `biz_` | 业务表 | `biz_contract`, `biz_approval` |
| `sys_` | 系统表 | `sys_user`, `sys_config` |
| `log_` | 日志表 | `log_login`, `log_operation` |

## 三、核心业务表

### 3.1 用户表 `sys_user`

```sql
CREATE TABLE `sys_user` (
    `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '用户ID',
    `username` VARCHAR(50) NOT NULL COMMENT '用户名',
    `password` VARCHAR(255) NOT NULL COMMENT '密码(bcrypt加密)',
    `real_name` VARCHAR(50) COMMENT '真实姓名',
    `phone` VARCHAR(20) COMMENT '手机号',
    `email` VARCHAR(100) COMMENT '邮箱',
    
    -- 审批角色（7级审批链用）
    `approval_role` VARCHAR(50) NOT NULL COMMENT '审批角色: business_handler/business_reviewer/risk_auditor/finance_handler/finance_reviewer/scm_director/invest_director',
    
    -- RBAC角色（菜单权限用）
    `rbac_role_id` INT UNSIGNED COMMENT 'RBAC角色ID',
    
    -- 超管标识
    `is_superuser` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否超级管理员: 0否 1是',
    
    -- 部门
    `dept_id` INT UNSIGNED COMMENT '部门ID',
    
    -- 电子签名
    `signature` VARCHAR(500) COMMENT '电子签名图片URL',
    
    -- 状态
    `status` TINYINT(1) NOT NULL DEFAULT 1 COMMENT '状态: 0停用 1启用',
    
    -- 审计字段
    `last_login_at` DATETIME COMMENT '最后登录时间',
    `last_login_ip` VARCHAR(50) COMMENT '最后登录IP',
    `created_by` INT UNSIGNED COMMENT '创建人',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_by` INT UNSIGNED COMMENT '更新人',
    `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_username` (`username`),
    KEY `idx_approval_role` (`approval_role`),
    KEY `idx_rbac_role_id` (`rbac_role_id`),
    KEY `idx_dept_id` (`dept_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 3.2 合同表 `biz_contract`

```sql
CREATE TABLE `biz_contract` (
    `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '合同ID',
    
    -- 合同基本信息
    `contract_no` VARCHAR(50) NOT NULL COMMENT '合同编号',
    `title` VARCHAR(200) NOT NULL COMMENT '合同名称',
    `contract_type` VARCHAR(20) NOT NULL COMMENT '合同类型: payment付款/business业务',
    
    -- 甲乙方
    `party_a` VARCHAR(200) NOT NULL COMMENT '甲方(客户)',
    `party_b` VARCHAR(200) NOT NULL COMMENT '乙方(本司)',
    
    -- 金额
    `amount` DECIMAL(15,2) NOT NULL COMMENT '合同金额',
    `amount_in_words` VARCHAR(100) COMMENT '金额大写',
    
    -- 签订信息
    `sign_date` DATE COMMENT '签订日期',
    `department` VARCHAR(100) COMMENT '申请部门',
    
    -- 业务信息
    `customer_id` INT UNSIGNED COMMENT '客户ID',
    `business_type` VARCHAR(50) COMMENT '业务类型',
    `remark` TEXT COMMENT '备注',
    
    -- 附件
    `attachments` JSON COMMENT '附件列表[{name, url}]',
    
    -- 审批流状态
    `status` VARCHAR(20) NOT NULL DEFAULT 'draft' COMMENT '状态: draft草稿/pending审批中/approved已通过/rejected已驳回',
    `current_step` INT NOT NULL DEFAULT 0 COMMENT '当前审批步骤(0-6)',
    
    -- 发起人
    `created_by` INT UNSIGNED NOT NULL COMMENT '创建人ID',
    
    -- 审计字段
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_contract_no` (`contract_no`),
    KEY `idx_status` (`status`),
    KEY `idx_current_step` (`current_step`),
    KEY `idx_created_by` (`created_by`),
    KEY `idx_created_at` (`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='合同表';
```

### 3.3 审批记录表 `biz_approval`

```sql
CREATE TABLE `biz_approval` (
    `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '审批ID',
    
    -- 关联合同
    `contract_id` INT UNSIGNED NOT NULL COMMENT '合同ID',
    
    -- 审批人信息
    `approver_id` INT UNSIGNED COMMENT '审批人ID',
    `approver_name` VARCHAR(50) COMMENT '审批人姓名',
    `approver_role` VARCHAR(50) NOT NULL COMMENT '审批时角色',
    
    -- 审批信息
    `step` INT NOT NULL COMMENT '审批步骤(0-6)',
    `action` VARCHAR(20) NOT NULL COMMENT '动作: approve通过/reject驳回/withdraw撤回/transfer转交/cosign加签',
    `comment` TEXT COMMENT '审批意见',
    
    -- 电子签名快照
    `signature_snapshot` TEXT COMMENT '审批时电子签名图片(base64)',
    
    -- 驳回原因
    `reject_reason` TEXT COMMENT '驳回原因(当action=reject时)',
    
    -- 转交信息
    `transfer_to_id` INT UNSIGNED COMMENT '转交给的用户ID(当action=transfer时)',
    
    -- 审批时间地点
    `approval_ip` VARCHAR(50) COMMENT '审批操作IP',
    `approval_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '审批时间',
    
    PRIMARY KEY (`id`),
    KEY `idx_contract_id` (`contract_id`),
    KEY `idx_approver_id` (`approver_id`),
    KEY `idx_step` (`step`),
    KEY `idx_approval_time` (`approval_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='审批记录表';
```
