## 一、系统概述

### 1.1 项目定位

山东出版供应链管理公司业务平台，是面向文旅行业的 **企业级B2B业务管理系统**，集供应链管理、合同审批、财务管控、票务代理销售于一体。

**核心业务范围：**
1. **供应链管理** — 景区/文旅甲方档案管理、供应商资质管控
2. **合同审批** — 7级审批流，支持付款审批单/业务审批单
3. **票务代理** — 对接美团、抖音等OTA平台，实现多渠道票务销售与统一管理
4. **财务管控** — 进账出账、结算付款、发票管理、银行对账

| 措施 | 实现方式 | 优先级 |

| 密码加密 | bcrypt哈希存储 | P0 |
| SQL注入防护 | SQLAlchemy参数化查询 | P0 |
| XSS防护 | 前端DOMPurify + 后端过滤 | P1 |
| 传输加密 | HTTPS + 请求体加密 | P1 |
| CSRF防护 | SameSite Cookie + Token验证 | P2 |
| 敏感数据脱敏 | 手机号脱敏（138****5678） | P2 |
| 操作审计 | 登录日志 + 操作日志 | P1 |
| 渠道密钥加密 | RSA加密存储 | P0 |

## 八、模块详细说明

### 8.1 审批引擎（核心模块）

审批引擎是系统的核心业务模块，负责管理合同从创建到归档的完整生命周期。

**状态机：**
```
draft ──提交──► pending ──审批通过──► approved
  │              │
  │              └──审批驳回──► rejected
  │
  └──删除──► (deleted)
```

**核心接口：**
| 接口 | 方法 | 说明 |
|------|------|------|
| `/contracts` | POST | 创建合同 |
| `/contracts/{id}/submit` | POST | 提交审批 |
| `/contracts/{id}/approve` | POST | 审批通过 |
| `/contracts/{id}/reject` | POST | 审批驳回 |
| `/contracts/{id}/withdraw` | POST | 撤回 |
| `/contracts/{id}/transfer` | POST | 转交 |
| `/contracts/{id}/cosign` | POST | 加签 |

### 8.2 渠道集成模块

负责与美团、抖音等OTA平台对接。

**对接内容：**
| 平台 | 接口 | 用途 |
|------|------|------|
| 美团 | 订单同步 | 获取销售订单 |
| 美团 | 账单结算 | 获取结算账单 |
| 美团 | 退款查询 | 查询退款订单 |
| 抖音 | 订单同步 | 获取销售订单 |
| 抖音 | 账单结算 | 获取结算账单 |

### 8.3 财务模块

处理进账、出账、对账等财务相关业务。

**核心功能：**
| 功能 | 说明 |
|------|------|
| 进账确认 | 确认OTA平台销售款到账 |
| 平台对账 | 与美团/抖音账单核对 |
| 银行对账 | 与银行流水核对 |
| 出账付款 | 与景区/文旅甲方结算付款 |
