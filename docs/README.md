## 文档版本约定

| 状态 | 含义 |
|------|------|
| `v1.x` | 现状分析类文档，基于现有系统评估 |
| `v2.x` | 设计规划类文档，定义未来系统 |
| `已签字` | 甲方已确认的正式版本 |

## 阅读顺序建议

### 内部技术团队
1. `02-现状与技术评估/v1现状盘点.md` - 了解现有系统
2. `02-现状与技术评估/技术债务清单.md` - 了解待解决问题
3. `03-设计/概要设计文档.md` - 了解系统架构
4. `03-设计/数据库设计.md` - 了解数据模型

### 甲方/外部评审
1. `01-需求/PRD-产品需求文档.md` - 业务背景和场景
2. `01-需求/SRS-需求规格说明书.md` - 功能范围和验收标准
