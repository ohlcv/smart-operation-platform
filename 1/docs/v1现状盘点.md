| 子需求 | 描述 | 状态 |
|--------|------|------|
| 账号密码登录 | 用户名+密码认证 | ✅ |
| JWT Token | 无状态认证 | ✅ |
| 角色识别 | 自动识别用户角色 | ✅ |
| 超管放行 | 超级管理员不受权限限制 | ✅ |

    Role.FINANCE_REVIEWER,    # 财务复核
